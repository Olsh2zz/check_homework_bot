# check_homework_bot

Telegram-бот для сдачи домашних работ. Студент присылает работу боту, преподаватель проверяет её вручную и ставит баллы. Студент получает ответ: ✅ работа принята или ❌ её нужно доработать, с комментарием.

```
✅ Работа «Лабораторная 3» принята
Баллы: 7.5/10
Комментарий: Аккуратная работа
```

```
❌ Работу «Лабораторная 4» нужно доработать
Баллы: 4/10
Комментарий: Нет вывода в конце отчёта

[🔁 Исправить] [❓ Уточнить]
```

Всё управление идёт кнопками. Единственная команда `/start` отправляется сама при первом открытии бота.

## Кто есть кто

Преподаватель один. Бот узнаёт его по Telegram ID, который задан в настройках. Все остальные, кто пишет боту, считаются студентами. Аккаунт преподавателя сдавать работы не может.

Бот работает только в личных чатах.

## Студент

### Регистрация

При первом запуске бот спрашивает ФИО и номер группы. ФИО должно состоять хотя бы из двух слов. Пока студент не зарегистрирован, остальные действия недоступны. Изменить данные можно кнопкой «👤 Профиль».

### Сдача работы

1. Студент нажимает «📤 Сдать работу».
2. Бот спрашивает название работы, например «Лабораторная 3». Списка заданий нет, студент подписывает работу сам.
3. Студент присылает работу: текст, ссылки, фото, файлы. Сообщений может быть до 30, альбомы тоже принимаются. Видео и аудио нужно отправлять как файл.
4. Кнопка «✅ Отправить» передаёт работу преподавателю. Кнопка «Отмена» удаляет всё присланное.

Пустую работу отправить нельзя. После отправки студент получает сообщение, что работа ушла на проверку.

### Мои работы

Кнопка «📚 Мои работы» показывает список работ:

```
Ваши работы

✅ Лабораторная 1: 7/10
✅ Лабораторная 2: 4.5/5
❌ Лабораторная 3 (попытка 2)
⏳ Лабораторная 4

Сумма баллов за принятые работы: 11.5/15
```

⏳ значит, что работа ждёт проверки, ✅ принята, ❌ отправлена на доработку. У каждой работы показана только последняя попытка.

Под списком есть кнопки:

- «↩️ Отозвать» у работы, которая ещё не проверена. Отозванная работа пропадает из очереди преподавателя. Проверенную работу отозвать нельзя.
- «🔁 Исправить» у работы, отправленной на доработку.

### Доработка

Под сообщением об отклонённой работе две кнопки.

«🔁 Исправить» начинает пересдачу. Студент присылает новую версию, название остаётся прежним. Число попыток не ограничено. Пересдать можно только последнюю попытку: если новая версия уже отправлена, старую кнопку бот не примет.

«❓ Уточнить» позволяет задать вопрос по комментарию. Студент пишет вопрос одним сообщением, ответ преподавателя приходит через бота. Задать вопрос можно только по своей работе.

## Преподаватель

### Новая работа

Когда студент отправляет работу, преподавателю приходит её содержимое в том же порядке, в каком студент его присылал, и карточка:

```
📄 Лабораторная 3
Студент: Иванов Иван (ИВТ-21), @ivanov
Попытка: 2
Сдано: 13.11.2026 10:05
Прошлый комментарий: Нет вывода в конце отчёта

⏳ Ждёт проверки

[✅ Принять] [❌ На доработку]
```

Номер попытки и прошлый комментарий показывают, что это пересдача.

### Оценка

«✅ Принять»: бот просит баллы, затем комментарий. Комментарий можно пропустить кнопкой «Без комментария».

«❌ На доработку»: бот просит комментарий (он обязателен), затем баллы. Баллы можно пропустить кнопкой «Без баллов».

Баллы вводятся как «балл/максимум», оба числа преподаватель задаёт сам: `7/10`, `7,5/10`, `7 из 10`. Если балл больше максимума или формат другой, бот объясняет ошибку и спрашивает ещё раз.

После оценки студент получает результат, а карточка у преподавателя меняется: кнопки пропадают, вместо «Ждёт проверки» появляется итог. Оценить работу можно один раз. Кнопка «Отмена» на любом шаге оставляет работу в очереди.

Если студент отозвал работу, пока преподаватель вводил оценку, оценка не сохраняется, а преподаватель видит сообщение, что работа отозвана.

### Очередь проверки

Кнопка «📥 Очередь проверки» показывает все непроверенные работы, начиная с самых давних:

```
Ждут проверки: 2

1. Петров Пётр (ИВТ-22): Лабораторная 2, 3 дн.
2. Иванов Иван (ИВТ-21): Лабораторная 4, сегодня
```

Нажатие на работу присылает её содержимое и карточку заново.

### Вопросы студентов

Вопрос приходит с названием работы, комментарием преподавателя и кнопкой «Ответить». Ответ уходит студенту через бота, личный аккаунт преподавателя студент не видит.

### Напоминания

Раз в сутки бот проверяет очередь. Если есть работы, которые ждут проверки дольше двух дней, преподаватель получает сообщение с их числом и кнопкой «Открыть очередь».

## Что хранит бот

Бот хранит ФИО и группу студентов, все попытки каждой работы с баллами и комментариями, вопросы и ответы. Файлы и фото он не скачивает: Telegram выдаёт каждому вложению идентификатор, и бот пересылает вложение преподавателю по нему.
